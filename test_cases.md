# Test Cases

В данной ветви размещаются материалы, связанные с разработкой тест-кейсов для веб-приложения Комитета по энергетике и инженерному обеспечению.

Основные направления тестирования:
1) проверка навигации;
2) проверка отображения контактной информации;
3) проверка блока новостей;
4) проверка кнопок быстрого доступа;
5) проверка адаптивности интерфейса.
